# MIMOUVERSE

**MIMOUVERSE** est une plateforme de lecture moderne réunissant livres, mangas, dictionnaire, assistant IA et communauté de lecteurs.

## Structure prévue
- 🏠 Accueil
- 📚 Livres
- 🗯️ Manga
- 📖 Dictionnaire
- 🤖 MIA — assistant intelligent
- 💬 Communauté, commentaires et notes
- 👤 Profils lecteurs
- ❤️ Favoris et 🕘 historique de lecture
- 👑 Administration sécurisée

## Stack
React + Vite + React Router + Lucide React. La base de données, l’authentification, le stockage et l’IA seront branchés progressivement.

> Ne jamais placer de mot de passe, clé API privée ou secret dans le code frontend.
